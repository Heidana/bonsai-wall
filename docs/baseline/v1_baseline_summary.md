## structure_distance baseline (median pairwise, seeds 1-30)

Proxy definition (V1 has no 3D skeleton): mean of (1 - IoU of height-normalised silhouettes) and total-variation distance of the area-weighted pad-centre angle histogram (24 bins).

`raw` is the spec's definition. V1 mirrors each tree left or right at random, so `raw` counts a mirrored copy of the same tree as different, which inflates asymmetric styles (a 1.5x target above 1.0 is unreachable). `canonical` first flips each tree so its silhouette mass lies on the +x side, then applies the same formula. DEVIATIONS D8 proposes `canonical` as the variety test.
